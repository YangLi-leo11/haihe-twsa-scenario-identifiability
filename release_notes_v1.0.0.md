# Release notes v1.0.0

- Provides the strict recursive validation series for November 2020-October 2025.
- Includes the publicly distributable Figure 2a source series and verifies the
  reported panel metrics. The complete Figure 2 is supplied as a reference image
  because restricted groundwater records are not distributed.
- Provides the 12-84 month analogue evaluation tables and Figure 3 workflow.
- Specifies the groundwater bootstrap as overlapping non-circular six-month blocks,
  2,000 replicates and seed 120.
- Includes processed climate-scenario, risk and residual-pathway inputs for Figures
  4-6 and the 2100 numerical checks.
- Documents HydroBASINS, GRACE/GRACE-FO, CMIP6 and groundwater access boundaries.
- Releases original repository code and documentation under the MIT License without
  relicensing third-party data.
- Uses numerical and source-data checks as the primary reproduction criteria;
  reference-image hashes are environment diagnostics.
